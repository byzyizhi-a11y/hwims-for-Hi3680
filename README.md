## hwims是给华为手机用来注册ims的一个应用，原厂hwims无法正常在第三方rom中运行
这个项目对于hwims进行了对于AOSP的移植，此应用需要配合一些sh可执行文件以及我自己编译的imsfix应用进行使用
0.1版本目前还是很不稳定，目前已经在huawei LYA-AL10上测试，很不稳定，ims状态会掉，需要我后续更新
